\# Security Policy



\## Reporting a Vulnerability



If you discover a security vulnerability in this repository, please do not

report it publicly through GitHub Issues or pull requests.



Instead, report the issue privately to the repository owner with:



\- A clear description of the vulnerability

\- Steps to reproduce the issue

\- Potential impact

\- Any relevant screenshots, logs, or proof of concept



Please allow reasonable time for the issue to be reviewed and addressed

before publicly disclosing the vulnerability.



\## Scope



This policy applies to the code, configuration, and assets maintained in

this repository.



\## Responsible Disclosure



We appreciate responsible security research and coordinated disclosure.

Security researchers who report valid vulnerabilities in good faith will be

treated respectfully and their reports will be handled confidentially.
